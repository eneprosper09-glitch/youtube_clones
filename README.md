# youtube_clones
# 🎬 YouTube Clone

A fully functional YouTube clone built with **HTML, CSS, and JavaScript**. All data is stored locally in your browser using localStorage.

🔗 **Live Demo:** [https://eneprosper09-glitch.github.io/youtube_clones/](https://eneprosper09-glitch.github.io/youtube_clones/)

## ✨ Features

### 🏠 Homepage
- Video grid with thumbnails
- Category filter (Music, Gaming, News, Sports, etc.)
- Search functionality
- Horizontal scrolling Shorts section
- Recommended videos section

### ▶️ Watch Page
- YouTube video player (iframe embed)
- Like / Dislike buttons (saved in localStorage)
- Subscribe / Unsubscribe
- Watch Later
- Comments section (add, like, delete)
- Suggested videos

### 📺 Your Channel
- Channel banner and avatar
- Channel stats (subscribers, videos, views)
- Customize channel (name, handle, avatar, description)
- Video tabs (Videos, Shorts, Playlists, About)
- Create and manage playlists

### 📚 Your Videos
- Upload new videos
- Edit video details
- Delete videos
- View your uploaded content

### ❤️ Liked Videos
- View all videos you've liked
- Click to watch again

### ⏰ Watch Later
- Save videos to watch later
- Remove from watch later
- Clear all

### 📜 History
- Automatically saves watched videos
- Clear history

### 🔔 Notifications
- Like notifications
- Comment notifications
- Subscribe notifications
- Upload notifications
- Mark as read
- Filter by type

### 👤 Profile
- Edit profile (name, handle, email)
- Change avatar
- Stats dashboard
- Dark Mode toggle
- Notification toggle
- Clear all data
- Sign out

### 🎮 Explore
- Trending videos
- Music
- Gaming
- News
- Sports
- Movies & TV

### 📤 Create
- Upload new videos with thumbnail
- Add title, description, category
- Paste YouTube URL
- Add tags

---

## 🛠️ Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling (YouTube-inspired dark theme)
- **JavaScript (Vanilla)** - All functionality
- **localStorage** - Data persistence
- **YouTube API** - Video embedding
